# Кадастр.Помощник KB-100

> Полностью офлайн ИИ-ассистент для кадастровых инженеров.
> Модель работает на вашей машине — данные не покидают устройство.

## Возможности

- **Чат-консультант** — отвечает по ФЗ-218, ФЗ-221, приказу П/0082
- **Проверка техпланов** — загружаете XML, получаете список замечаний со ссылками на пункты П/0082
- **Карточка объекта** — сбор сведений + генерация чек-листа документов
- **Нормативная база** — поиск по встроенным текстам ФЗ-218, ФЗ-221, П/0082

## Технологии

- **ИИ-движок**: DeepSeek R1 14B (бесплатно, MIT) через Ollama
- **Фолбэк**: WebLLM в браузере (модель DeepSeek-R1-Distill-Qwen-7B через WebGPU)
- **База знаний**: IndexedDB + BM25 поиск (без внешних эмбеддингов)
- **Никаких внешних API** — после установки Ollama всё работает офлайн

## Установка (5 минут)

### 1. Поставить Ollama

Скачать с https://ollama.com/download — версии для Windows, macOS, Linux.

### 2. Скачать модель

```bash
ollama pull deepseek-r1:14b
# для слабого железа:
ollama pull deepseek-r1:7b
```

Один раз скачивается ~9 ГБ, далее работает офлайн.

### 3. Запустить Ollama

```bash
ollama serve
# слушает на http://localhost:11434
```

### 4. Залить репозиторий на GitHub

```bash
git init
git add .
git commit -m "KB-100: initial commit — локальный ИИ-ассистент"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/kadastrhelp-local-llm.git
git push -u origin main
```

### 5. Включить GitHub Pages

В настройках репозитория → **Settings → Pages** →
- **Source**: Deploy from a branch
- **Branch**: `main`, folder: `/ (root)`
- **Save**

Через 1-2 минуты сайт будет доступен по адресу:
`https://ВАШ_ЛОГИН.github.io/kadastrhelp-local-llm/`

### 6. Важно: настроить CORS в Ollama

Поскольку GitHub Pages работает по HTTPS, а Ollama — по HTTP, нужно разрешить cross-origin:

**Linux/macOS:**
```bash
OLLAMA_ORIGINS="https://ВАШ_ЛОГИН.github.io" ollama serve
```

**Windows (PowerShell):**
```powershell
$env:OLLAMA_ORIGINS="https://ВАШ_ЛОГИН.github.io"
ollama serve
```

Или для теста локально — откройте `index.html` через локальный сервер:
```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

## Что умеет ассистент

### 1. Чат-консультант

Задаёте вопрос — ассистент отвечает с цитатами из законов:

```
Q: Какие документы нужны для кадастрового учёта нового здания?
A: Для кадастрового учёта нового здания требуются (ч. 4 ст. 14 ФЗ-218):
   1. Технический план здания (XML + графическая часть PDF)
   2. Правоустанавливающий документ на земельный участок
   3. Разрешение на ввод здания в эксплуатацию
   ...
```

### 2. Проверка техплана

Загружаете XML техплана — получаете:

- **Структурную проверку** (парсинг без ИИ): кадастровый номер, тип, площадь, инженер, дата, приложения
- **Замечания по П/0082** с уровнями критичности: КРИТИЧНО / ВАЖНО / ИНФО
- **Ссылки на пункты приказа** для каждого замечания
- **Источники** — релевантные фрагменты П/0082

### 3. Карточка объекта + чек-лист

Заполняете карточку (кадастровый номер, тип, площадь, адрес) → нажимаете «Сформировать чек-лист документов» — ИИ выдаёт список документов по группам: правоустанавливающие, технические, удостоверяющие личность.

### 4. Поиск по нормативке

Введите запрос — получите релевантные фрагменты из ФЗ-218, ФЗ-221, П/0082 с подсветкой найденных слов.

## «Один раз научили» — как это работает

Ассистент обучен через три слоя промпт-инжиниринга (без fine-tuning):

1. **Системный промпт** — роль «кадастровый инженер с 10-летним стажем»
2. **Few-shot примеры** — 3-9 примеров «вопрос → ответ» для каждой задачи
3. **RAG по нормативке** — поиск релевантных пунктов закона в IndexedDB

Это эквивалентно обучению нового сотрудника: даём должностную инструкцию, набор примеров правильной работы и доступ к справочной библиотеке. Расширять «опыт» можно, добавляя новые few-shot примеры в `data/few-shot-examples.js`.

## Ограничения

- ❌ Не делает XSD-валидацию XML (только структурный парсинг)
- ❌ Не получает выписки ЕГРН автоматически (нужна интеграция с Госуслуги API)
- ❌ Не отправляет техплан в Росреестр (нужна ЭЦП и отдельная интеграция)
- ⚠ DeepSeek R1 может галлюцинировать на редких терминах — сверяйте важное с первоисточником
