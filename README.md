# Кадастр.Помощник KB-100 (WebLLM, без установки программ)

Модель работает **в браузере** (Chrome/Edge 113+, WebGPU). Ставить ничего не нужно.

## Запуск
1. Положите эти файлы поверх вашего репозитория (папку `data/` с JSON не трогайте).
2. GitHub → Settings → Pages → ветка `main`, папка `/ (root)`.
3. Откройте `https://ЛОГИН.github.io/kadastrhelp-local-llm/` → ⚙ → выберите модель → «Загрузить модель» (один раз, несколько ГБ).
4. Проверка приватности: после загрузки отключите интернет — чат должен работать (F12 → Network: запросов с текстом нет).

Опционально: скачайте `https://cdn.jsdelivr.net/npm/@mlc-ai/web-llm@0.2.79/+esm` в `vendor/web-llm.js`, чтобы не зависеть от CDN.

## Формат data/*.json
Массив `[{ "location": "ст. 14, ч. 4", "text": "…" }]` или объект с полем `chunks`/`fragments`/`items`/`articles`.

## Ограничения
Проверка XML ищет теги по типичным именам и может не найти поля в вашей схеме. Ответы ИИ нужно сверять с первоисточником.
